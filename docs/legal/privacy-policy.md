〔運営者名〕（以下「運営者」）は、Yunagi（以下「本サービス」）における利用者の情報を、以下のとおり取り扱います。

## 1. 基本方針

本サービスは、利用者が作成した TODO、障害・詰まり、振り返り、ノート等の内容（以下「業務データ」）を、利用者の端末内に保存します。運営者は、利用者が有料のクラウド同期を有効にした場合を除き、業務データを取得しません。

## 2. 取得する情報

| 情報 | 取得する場面 | 目的 |
| --- | --- | --- |
| アプリの版、OS とアーキテクチャ、IP アドレス、アクセス日時 | 更新の確認時（既定で有効。設定で無効にできます） | 適切な更新の配布 |
| 購入者の氏名・メールアドレス・決済情報 | サポーターライセンス・有料オプションの購入時（販売プラットフォーム経由） | ライセンスの発行、問い合わせ対応 |
| ライセンスキー、IP アドレス、アクセス日時 | 利用者がアプリにライセンスキーを入力し、確認の操作をしたとき（1 回の操作につき 1 回。利用者の操作なしに、アプリが自動で送信することはありません）。販売プラットフォームへ直接送信されます | ライセンスキーが有効であることの確認 |
| 暗号化された業務データ | クラウド同期の利用時（将来） | 端末間の同期。運営者は内容を復号できません |
| 利用統計 | 利用者がオプトインした場合のみ | 品質改善。業務データの内容は含みません |
| 問い合わせ内容 | 問い合わせ時 | 回答と改善 |

## 3. 第三者への提供と外部送信

1. 運営者は、法令に基づく場合を除き、本人の同意なく個人情報を第三者に提供しません。
2. 決済は〔販売プラットフォーム名〕が行い、運営者はカード番号等を保持しません。
3. 利用者がAIエージェント（Claude Code、Codex 等）に読み取りを許可した場合、エージェントは端末内で業務データを読み取り、そのエージェントの仕組みに従ってAIサービスへ送信することがあります。その取扱いは、利用者と各AIサービスとの契約・ポリシーに従います。本サービスがAIサービスへ直接送信することはありません。
4. 利用者が外部ツール（Linear、Jira 等）と連携した場合、本サービスは利用者の端末から連携先の API へ直接データを送受信します。その取扱いは連携先の規約・ポリシーに従います。
5. 更新ファイルは〔配布ホスト名〕から配信され、更新確認時のアクセス記録（IP アドレス、アクセス日時等）は同社のポリシーに従って扱われます。
6. ライセンスキーの確認は、利用者の端末から〔販売プラットフォーム名〕へ直接行われます。送信するのはライセンスキーと販売元を示す識別子のみで、業務データは送信しません。確認時のアクセス記録（IP アドレス、アクセス日時等）は同社のポリシーに従って扱われます。ライセンスキーを入力しない場合、この送信は行われません。

〔注記（確定版では削除）：販売プラットフォームの第一候補は Polar で、同社が販売者（Merchant of Record）となる方式である（要件定義書 9章。2026-11-12）。最終決定は、日本の消費税・インボイスの扱いの確認の後。同社が販売者となる場合に、購入者の情報をだれが取得し、運営者がどの範囲を受け取るのか（2章の表の「購入者の氏名・メールアドレス・決済情報」の書き方）と、国外の事業者への送信についての記載の要否は、確定版（YUN-106）で弁護士の確認を受けて直す。〕

## 4. 安全管理

外部ツールの認証情報は端末の OS キーチェーンに保存します。クラウド同期はエンドツーエンド暗号化を前提とし、暗号鍵は利用者の端末にのみ保持されます。

## 5. 開示・訂正・削除

運営者が保有する個人情報の開示・訂正・削除の請求は、〔問い合わせ窓口〕までご連絡ください。
