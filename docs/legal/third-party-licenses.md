# サードパーティライセンス表記の方針

## 1. 目的

Yunagi が利用するオープンソースソフトウェア（OSS）のライセンス条件を満たし、著作権表示とライセンス本文を利用者が確認できるようにする。

## 2. 方針

1. Rust の依存は `cargo-about` 等、JavaScript の依存はライセンス収集ツールで、ライセンス本文と著作権表示を自動収集する。
2. 収集結果は `THIRD_PARTY_LICENSES.md` としてリリースごとに CI で生成し（ビルド・配布手順書 3章）、アプリの「設定 → このアプリについて」から表示する。
3. 許可するライセンスの一覧を定め（例：MIT、Apache-2.0、BSD-2/3-Clause、ISC、Zlib、MPL-2.0。フォントに限り OFL-1.1）、それ以外が混入した場合は CI で検出して止める。
4. GPL・AGPL 系のライセンスを持つ依存は、配布形態への影響を確認するまで採用しない。
5. フォントを同梱する場合は、フォントのライセンス（SIL OFL 等）も同じ表記に含める（例：Inter、JetBrains Mono を同梱する場合。同梱の可否はデザインガイドで決める）。
   - Inter は npm の `@fontsource-variable/inter`（OFL-1.1）で同梱する（デザインガイド 4章）。JavaScript の依存として、ほかの依存と同じツールで収集する。

## 3. 未決事項

- Yunagi 本体のソースコードを公開するか、公開する場合のライセンス。非公開とする場合も、配布・Issue・脆弱性報告用の公開リポジトリ（インストールスクリプト、CHANGELOG、SECURITY.md を置く）は別に用意する（ビルド・配布手順書 1章）。
