## 2. MVP の内訳（目安）

1. 基盤：コア、データモデル、論理日付、自動保存、バックアップ
2. 画面：整理モード、ノートモード、持ち越し、検索パレット、設定、Markdown 書き出し
3. 操作：ショートカット、IME 対応、Vimモード
4. 接続口：ローカル API、CLI、MCP サーバー、権限と変更履歴、`agent setup`
5. 配布：CI、インストールスクリプト、Homebrew tap、自動更新
6. 公開準備：利用者ガイド（日英）、法務文書、公式サイト、販売ページ

## 3. 判断基準（案）

| 判断 | 基準の候補 |
| --- | --- |
| 有料機能 A に着手する | 週あたりの利用者数、連携要望の数、サポーターライセンスの購入数 |
| 有料機能 B に着手する | 複数端末利用の要望、運用体制（障害対応できる人員）の確保 |
| 有料署名・ストア配布に切り替える | 非エンジニア層からの問い合わせの増加、年間売上が署名費用を十分に上回ること |

具体的な数値は MVP 公開後の実績を見て設定する（TBD）。
