# 動作環境

## 対応する OS

| OS | 版 | アーキテクチャ |
| --- | --- | --- |
| macOS | 直近3世代（Apple Silicon）。Intel Mac は、対応する最後の macOS まで | arm64、x86_64 |
| Windows | 10、11 | x86_64、arm64 |
| Linux | 主要なディストリビューション。動作を確かめる対象は、Ubuntu LTS（GNOME。Wayland と X11）と Fedora（KDE。Wayland） | x86_64、arm64 |

リリース前に動作を確かめられなかった組み合わせは、ダウンロードの案内とリリースノートで「試験提供（動作未保証）」と明記します。

## そのほか

- 管理者の権限は要りません。インストールスクリプトで入れると、ログインしている利用者だけが使う形で入ります。
- すべての機能は、ネットワークがなくても動きます。通信するのは、更新の確認（既定で有効。設定で無効にできます）と、自分で有効にした機能だけです。更新の確認で送る情報は版・OS・アーキテクチャだけです。
- Linux の AppImage の起動には、FUSE 2 が要ります。Wayland では、OS 全体のショートカットが効かないことがあります。そのときの設定は[利用者ガイド 2章](/ja/guide/#2-最初の起動)にあります。
- 画面の表示は日本語と英語に対応しています。ライトとダークは OS の外観設定に合わせて切り替わります。
- ノートのデータは自分の PC のファイルとして保存します。保存先は設定で変えられます。
