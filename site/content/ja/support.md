# 問い合わせ

## 不具合の報告と要望

公開リポジトリの [GitHub Issues](https://github.com/misty-swan/yunagi/issues) で受け付けます（書き方のテンプレートがあります）。3営業日以内に最初の返事をすることを目標にしています。

次のことを書いてください。

- Yunagi の版（`yunagi --version`）
- OS とその版、CPU（Apple Silicon、Intel、x86_64、arm64）
- 日本語入力の種類（該当するとき）
- Vim モードが有効か無効か
- 再現の手順、期待した動き、実際の動き
- 診断情報（`yunagi doctor` の出力。ノートなどの業務データの内容は含まれません）

業務ノートなどの実際のデータは、貼らないでください。

## メール

GitHub のアカウントが無いときや、購入・ライセンスのことは、[support@getyunagi.com](mailto:support@getyunagi.com) へ送ってください。

## 脆弱性

公開の Issue には書かないでください。報告のしかたは[セキュリティ](/ja/security/)にあります。
