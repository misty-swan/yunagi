## 1. 案D「夕凪」の仕様（設計書へ書き戻す内容）

### 1.1 画面の骨組み

画面は「サイドバー」「上部のバー」「凪メーター」「本文（整理／ノート／ふりかえり）」「キーの案内」の5つで構成する。

**サイドバー**（幅 240px、背景 `--side`、右に 1px の `--rule`）

| 上から | 内容 |
| --- | --- |
| ロゴ | アイコン（24px）＋小文字の「yunagi」 |
| ナビ | Today（今日の残り件数）／ Archive（ふりかえり）／ Agents（未確認の変更の件数。選ぶと変更履歴 S-06）。Inbox（外部課題の受信箱 S-07）は、外部ツール連携（有料機能 A）を有効にした利用者にだけ Agents の上に表示する。MVP では出さない |
| Recent | 今日と、項目やノートのある直近の日（最大7日）。各行に、その日の海の様子を小さな波で、完了数／TODO数を右に。すべて終えた日は波が平らな夕陽色の線になる |
| 下端 | Settings（Mod+,）、状態（エージェントの接続、「Saved locally」または保存失敗、新しい版があるときは「New version」。サイドバーを閉じているときは「New version」を上部のバーの右側に出す） |

- **Mod+\\** で開閉する。ノートモードに入ると自動で閉じ（書くことに集中）、整理モードに戻ると元に戻す
- ウィンドウ幅 900px 未満では閉じる（Mod+\\ で明示的に開いたときだけ表示）
- 閉じているときは、上部のバーの左端にロゴを出す

**上部のバー**（高さ 60px）：左から「（閉じているときだけロゴ）」「‹ 日付 ›」「Today」「Board / Note の切り替え」…右端に「検索欄（押すとパレット、Mod+K）」「エージェントの未確認の変更（◆ 件数）」「保存中の点／保存できていません」。

- 日付は `10.29 Thu`（数字は等幅）。年は出さない（パレットの日付ジャンプでは `2026.10.28 Wed`）
- 「Today」は今日なら夕陽色の枠の印、ほかの日なら押せるボタン（「Today ⌘T」）になり、今日へ戻る
- ふりかえり画面では、日付と切り替えの代わりに「Archive」の見出しを出す

**キーの案内**（画面下端、1行）：その画面の主なキーを `⌘K Search` のように出す。整理・ノート・ふりかえりで内容を変える。

### 1.2 凪メーター

上部のバーの下に、空と海の景色を置く。整理モードでは高さ 112px、ノートモードでは 58px の小さい版、ふりかえり画面では出さない。

| 要素 | 意味 | 表し方 |
| --- | --- | --- |
| 太陽 | いまの時刻 | 始業（既定 9:00）から終業（既定 19:00）まで、左から右へ弧を描いて進む。終業を過ぎると水平線に半分沈む。過去の日は終業の位置、未来の日は始業の位置 |
| 波 | 残りの仕事 | 未完了の TODO と未解消の障害の数（全体に対する割合）が多いほど高い。0 件になると平らな線になる（＝凪） |
| 光の道 | 終えた仕事 | 完了・解消した割合が大きいほど、太陽の下の海面に映る光の線が長く（本数が多く）なる |
| 空 | 雰囲気 | `--sky-1` から `--sky-2` へのグラデーション。太陽の位置に合わせて背景にうっすら光が差す |

- 左上に文字で：時刻（今日）／「Day end」（過去の日）／「Not yet」（未来の日）、大きく残り件数と「LEFT」、続けて「TODO 6 · Blockers 3 · Done 3/9 · ↻ Carried 4」。残りが 0 件の日は「NAGI」と完了数だけを出す
- 03 3章のヘッダーにあった件数（完了数／TODO数、持ち越し件数、未解消の障害数）は、凪メーターに移す
- **動きは付けない**。操作や時刻に応じて、色と形がその場で切り替わるだけ（06 の「動かないこと」を守る）
- 読み上げ用に「残り 9 件（TODO 6・障害 3）、完了 3/9、持ち越し 4」をまとめて付ける
- 勤務時間（始業・終業）は設定（03 7章「一般」）で変えられるようにする。設定キーの案：`meter_hours`（既定 `09:00-19:00`）

### 1.3 ふりかえり（Archive）画面（新設）

過去の日を見返す画面。サイドバーの Archive、**Mod+Shift+L**、またはパレットのコマンドで開く。ロードマップ第2フェーズの「週の振り返り（F-13）」もこの画面に載せる想定。

| 部分 | 内容 |
| --- | --- |
| This week | 選んだ日を含む週（月〜金）の範囲と、週の合計（done・carried・resolved） |
| 週のカード | 月〜金の5枚。各カードに「その日の終わりの海」（太陽・波・光の道を小さく）と、日付・曜日・完了数／TODO数。今日のカードは現在の様子。未来の日は薄く、押せない |
| Daily notes | 記録のある直近の日（最大8日）。各行に小さな波、日付、完了数、振り返りの「良かったこと」「詰まったこと」の1行目（ラベル GOOD / STUCK） |
| プレビュー | 選んだ日の数字（Done / Carried / Resolved）、振り返りの全文、ノートの時刻付き見出しと各見出しの最初の2行。「Open ↵」でその日のボードを開く |

キー：← → で日を移動、Mod+[ / Mod+] で週を移動、Enter でその日を開く、Esc で元の画面に戻る。ダブルクリックでも開く。

### 1.4 各画面の変更点

**S-01 整理モード**

- 領域見出しは英字ラベル（TODO / BLOCKERS / REFLECTION、11px、字間 0.24em、大文字）。見出しの右に夕陽色で「6 left」（障害は `--warn` で「3 open」）
- 各行の先頭にチェック欄（TODO は丸、障害は角丸の四角、16px、枠 `--ring`）。完了・解消すると `--accent` で塗り、白抜きのチェックを出す。クリックでも切り替えられる
- エージェントが作った項目は、本文の後ろに「◆ Claude Code」のようにエージェント名を `--agent` で添える。未確認の変更がある項目は、行頭の余白に小さな菱形
- 解消メモは、取り消し線の本文の下の行に「→ メモ」（03 3章の「1行で表示」から変更）
- 持ち越し回数は、線で描いた ↻ と数字。3回以上は `--warn`
- 選択中の行：左端の 2px の線（`--accent-strong`）と、薄い夕陽色の面（`--sel`）
- レイアウト：A. 2段は列の比率 1.15 : 1、右側は障害・詰まりが内容の高さ、振り返りが残り。区切りは振り返りの上の罫線だけ
- 振り返りのテンプレート見出し（良かったこと等）は、夕陽色の小さな文字（「## 」はごく薄く）

**S-02 ノートモード**

- 本文の幅 680px を中央に。左に縦の細い線（時間軸）を引き、時刻付き見出しの位置に丸を置く。いまカーソルがある区間の丸は塗る
- 時刻付き見出しは、時刻を 26px・細字・夕陽色で大きく、件名を 17px で続ける（「## 」はごく薄く）
- 送信済みの行は、行末の外側に「→ TODO」「→ BLOCKER」を `--sea` の小さな英字で（03 4章・06 6章の「行頭に薄い印」から変更）
- 右側に「Outline」（その日の見出しの一覧。押すとその見出しへ移動）と「Sent」（TODO へ送った行数・障害へ送った行数）
- 凪メーターは小さい版（時刻と残り件数だけ）

**S-03 持ち越し**：パネルは `--surface`、角丸 14px、薄い影。背後は `--scrim` で覆ってぼかす。見出しは英字ラベル「CARRY OVER」と、文「前回の日（10.28 Wed）に残った項目」。チェックは丸。動きと選択肢は従来どおり。

**S-04 検索パレット**：パネルの形は S-03 と同じ。グループ見出し（GO TO DATE / COMMANDS / RESULTS）と種類（TODO / BLOCKER / REFLECTION / NOTE）は英字ラベル。一致した部分は太字の夕陽色。コマンドに「ふりかえり（Archive）を開く」「サイドバーを開く・閉じる」を追加。

### 1.6 文字

- 書体：欧文 Inter、和文は OS 標準（ヒラギノ角ゴ／游ゴシック／Noto Sans CJK）。ノートの等幅切り替えは従来どおり

### 1.7 余白・形

- 画面の左右余白 28px、サイドバー 240px、上部のバー 60px

### 1.8 ロゴとアプリアイコン

- ロゴ：アイコン＋小文字の「yunagi」（字間 0.05em）。06 8章の「水平線を思わせる1本の細い横線と小文字の yunagi」の方向性に沿う
- アプリアイコン（夕凪版）：角丸の正方形に、夕焼けの空と夜の海。水平線（58% の高さ）に半分沈んだ太陽と、海面の光の道。試作品とキャンバスのものはこの版
- 紙版（06 8章どおりの方向性）：生成りの角丸に、黒の水平線と小さな夕陽。ライトの印刷物などでの利用を想定
- 見本は Design キャンバス（claude.ai 上）の「ロゴとアプリアイコン」

### 1.9 文言の方針（06 7章に追加）

- **ラベル**（領域見出し、ナビ、凪メーター、キーの案内、件数、日付の表示、パレットのグループ名と種類）は、日本語 UI でも英語で書く
- **文**（状態の説明、確認、操作ボタン、空の状態、エラー、コマンド名）は各言語で書く。例：「今日やることを書く（Enter）」「保存できていません」「選んだものを持ち越す」
- 英字ラベルの語：Today / Archive / Inbox / Agents / Settings / Recent / Board / Note / TODO / Blockers / Reflection / left / open / Done / Carried / NAGI / Day end / Outline / Sent / This week / Daily notes / GOOD / STUCK / Open / Saved locally / New version
- 06 7章の日英対応表のうち「整理モード＝Board mode」「ノートモード＝Note mode」は、画面の切り替えでは短く Board / Note と表示する

## 4. 試作品の補足

### 見本データ

- 試作品の「今日」は **2026-10-29（木）** に固定。前日も平日にするため（2026-11-02 の前日は日曜、11-03 は祝日）
- 見本は夕方時点の内容。起動時の流れ（03 9章）を見せるため、読み込み時に S-03 を表示する
- 持ち越し回数は 02 の `carry_count` どおり。前回の日（10-28）の未完了 TODO を 0〜3 回にしてあり、持ち越すと ↻1〜↻4 になる。3回の項目には S-03 で「分割する／やめる」が出る
- ふりかえりのため 10-22・10-23・10-26・10-27 も用意。「古い feature flag を削除する」は 10-23 から毎日持ち越されている。10-22 はすべて完了した「凪」の日

### 動き（3章 K-04〜K-08・K-17 として設計書に採用したものの元）

- ↑ / ↓ で項目間を移動。行の途中の Enter で2件に分け、行頭の Enter で直上に追加。空の項目の Backspace で削除。何も書かずに離れた項目は消す
- 追加とその直後の入力は1回の取り消しで戻る。ノートから送る操作は取り消しの区切り
- 障害を解消すると、その場で解消メモを入力（Enter・Esc で確定）
- ノートの「- 」で始まる行の Enter で次の行も「- 」にする。中身のない「- 」の行で Enter を押すと消える
- Mod+Shift+H は現在時刻の見出しを、現在行が空ならその行に、そうでなければ空行をあけて次に入れる
- S-03：開いたときは全項目にチェック。Enter は「選んだものを持ち越す」。「分割する／やめる」は下の3つのボタンのどれでも反映。持ち越した項目は今日のリストの先頭へ
- S-04：空欄ではコマンドの一覧。「日付へ移動」→「コマンド」→「検索結果」の順。「昨日」は今日が基準
- 依頼文の書き出し（Mod+Shift+A）の書式は仮（05 の A-06 と合わせて決める）

### 書体

Inter と JetBrains Mono は同梱していない（依存なしで動かすため）。パソコンに入っていれば使い、なければ OS の標準書体で表示する。
