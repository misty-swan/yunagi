# yunagi 画面試作品（prototype/）

Yunagi の見た目と操作感を確かめるための、ブラウザで動く試作品です。デザインは案D「夕凪」です（経緯は NOTES.md）。

**位置づけ：見た目の参考です。仕様の正本は `docs/design/` です。**
画面の構成要素・表示する情報・遷移は 03 画面設計書、キー割当は 04 操作仕様書、色・文字・余白・文言は 06 デザインガイドが正本です。試作品と設計書が食い違う場合は設計書に従います（03 の 11章、06 の 9章）。試作品のコードは見本として扱い、本番（Tauri＋CodeMirror 6）には流用しません。

## 開き方

`prototype/index.html` をブラウザで開くだけで動きます。ビルドやサーバーは不要です。

- ファイルをダブルクリックするか、ブラウザの窓にドラッグする
- ターミナルからなら、Linux は `xdg-open prototype/index.html`、macOS は `open prototype/index.html`（既定のブラウザで開きます）

推奨ブラウザは Chrome（または Chromium 系）です。

- データは固定の見本です。保存はしません。再読み込みで初期状態に戻ります
- 試作品の「今日」は **2026-10-29（木）** に固定しています。前回の日は 10-28（水）。10-22〜10-27 の記録も少し入っています
- 開くと、その日の初回表示として **S-03 持ち越し** が出ます。Enter で確定すると、持ち越した項目（↻1〜↻4）が今日のボードに入ります
- 凪メーターの太陽は、パソコンのいまの時刻で動きます（試作品パネルで固定できます）

## 画面の見どころ

| 画面 | 開き方 | 見るところ |
| --- | --- | --- |
| 整理モード | 起動時 | 左のサイドバー（ロゴ、Today / Archive / Agents、Recent）、上部のバー（‹ 日付 ›、Today、Board / Note）、凪メーター、3つの領域 |
| ノートモード | Mod+J | サイドバーが閉じて集中表示に。時刻付き見出しが時間軸に並び、右に Outline と Sent |
| ふりかえり（Archive） | Mod+Shift+L、またはサイドバーの Archive | 1週間の海のカード、日ごとの振り返り、選んだ日のプレビュー |
| 持ち越し（S-03） | 起動時、または試作品パネル | 3回以上の項目の「分割する／やめる」 |
| 検索パレット（S-04） | Mod+K、または上部の検索欄 | 日付ジャンプ、コマンド、全日付の検索 |

**凪メーター**：太陽はいまの時刻（始業 9:00 から終業 19:00 まで左から右へ）、波は残りの TODO と障害（0 件で平らな「NAGI」）、海面に映る光の道は終えた仕事の多さを表します。すべて終えた日の例は 10-22 です（サイドバーの Recent から開けます）。

## 試作品だけの操作パネル

画面右下の破線の「試作品」ボタン（または **Alt+Shift+P**）で開きます。本番の画面にはないものです。

| 区分 | できること |
| --- | --- |
| 画面 | 持ち越しを最初からやり直す、検索パレット、Board ⇄ Note、Archive、前日へ、空の日（翌日）へ |
| 凪メーターの時刻 | いまの時刻／9:30／13:00／16:42／19:05 |
| レイアウト | A. 2段／B. 3列／C. 縦積み。「幅 820px で表示」で、幅 900px 未満では C になりサイドバーが閉じる規則を確かめられます |
| テーマ | OS に合わせる／ライト／ダーク |
| 言語 | 日本語／English（ラベルは両方とも英語。文が切り替わります） |
| 文字サイズ | 13／15／17／19px |
| ノートの書体 | 本文と同じ／等幅 |
| 状態 | 保存失敗を再現、保存中の点を出したままにする、新しい版がある、未確認の変更を戻す |
| Vimモード | 無効／有効（整理モードのリストのみ） |

## 操作キーの一覧

`Mod` は macOS では ⌘、Windows・Linux では Ctrl です。画面に出るキーの案内は本来の割当のままです。

### 代わりのキー（試作品だけ）

ブラウザが先に奪うキーがあるため、**Mod を使う割当の多くは、Mod の代わりに Alt（macOS は Option）を押しても動きます**。

- Chrome では **Mod+T（新しいタブ）と Mod+Shift+T（閉じたタブを開く）はページから止められません**。この2つは Alt+T・Alt+Shift+T を使ってください
- そのほか（Mod+J、Mod+K、Mod+1〜3、Mod+[ / ]、Mod+,、Mod+\\、Mod+Shift+R/B/H/A/L）は、通常はそのまま動きます。奪われる場合は Alt で代わりに操作してください
- 取り消し（Mod+Z など）、Mod+Enter、Mod+Backspace、Alt+↑/↓ には代わりのキーはありません

### 共通

| 操作 | 本来の割当 | 試作品の代わりのキー |
| --- | --- | --- |
| ノートモード ⇄ 整理モード | Mod+J | Alt+J |
| 前日・翌日へ移動（ふりかえりでは週の移動） | Mod+[ / Mod+] | Alt+[ / Alt+] |
| 今日へ戻る | Mod+T | **Alt+T** |
| 検索パレット | Mod+K | Alt+K |
| 設定 | Mod+, | Alt+,（案内の文言が出るだけ） |
| サイドバーを開く・閉じる（案D で追加） | Mod+\\ | Alt+\\ |
| ふりかえり（Archive）を開く・閉じる（案D で追加） | Mod+Shift+L | Alt+Shift+L |
| 取り消す／やり直す | Mod+Z ／ Mod+Shift+Z（Windows・Linux は Ctrl+Y も可） | — |
| Yunagi を前面に呼び出す | Mod+Alt+Y（Windows・Linux は Alt+Shift+Y） | 試作品では確認できません |

### 整理モード（S-01）

| 操作 | 本来の割当 | 試作品の代わりのキー |
| --- | --- | --- |
| 領域の移動（TODO／障害／振り返り） | Mod+1 / 2 / 3 | Alt+1 / 2 / 3 |
| 新しい項目を追加 | Enter（行末で） | — |
| 完了・解消の切替 | Mod+Enter（行頭のチェック欄のクリックでも可） | — |
| 項目の上下移動 | Alt+↑ / Alt+↓ | — |
| 項目の削除 | Mod+Shift+Backspace（試作品のコードは旧い初期値の Mod+Backspace のまま。本番の初期値は操作仕様書 2章） | — |
| 振り返りテンプレートの挿入 | Mod+Shift+R | Alt+Shift+R |
| 選んだ TODO を依頼文として書き出す | Mod+Shift+A | Alt+Shift+A |

試作品で決めた細かな動き：↑ / ↓ で項目間を移動、行の途中の Enter で2件に分け、行頭の Enter で直上に追加、空の項目の Backspace で削除、障害を解消するとその場で解消メモを入力（Enter・Esc で確定）、何も書かずに離れた項目は消えます。

### ノートモード（S-02）

| 操作 | 本来の割当 | 試作品の代わりのキー |
| --- | --- | --- |
| 現在行（選択中なら各行）を TODO へ送る | Mod+Shift+T | **Alt+Shift+T** |
| 現在行（選択中なら各行）を障害へ送る | Mod+Shift+B | Alt+Shift+B |
| 時刻付き見出しの挿入 | Mod+Shift+H | Alt+Shift+H |

- 送った行には行末の外側に「→ TODO」「→ BLOCKER」が付きます。本文を書き換えると外れます
- 「- 」で始まる行の Enter で、次の行も「- 」で始まります
- 行の右クリックからも送れます。右の Outline の見出しを押すと、その見出しへ移動します

### ふりかえり（Archive）

| 操作 | キー |
| --- | --- |
| 日を選ぶ | ← / → |
| 週を移動 | Mod+[ / Mod+] |
| 選んだ日を開く | Enter（またはダブルクリック、「Open」） |
| 元の画面に戻る | Esc |

### S-03 持ち越し

| 操作 | キー |
| --- | --- |
| 項目の移動 | j / k、または ↑ / ↓ |
| 選択の切替 | Space |
| 確定（選んだものを持ち越す） | Enter |
| 後回し | Esc |
| 「分割する」「やめる」へ移る | Tab（戻るのは Shift+Tab） |
| 分割の入力欄を抜ける | Esc |

### S-04 検索パレット

| 操作 | キー |
| --- | --- |
| 開く・閉じる | Mod+K（代わりのキーは Alt+K）、Esc |
| 候補の移動・実行 | ↑ / ↓、Enter |

`2026-10-28`、`10-28`、`10/28`、`yesterday`、`昨日`、`今日`、`明日` などは日付ジャンプになります（試作品の「今日」が基準）。

### Vimモード（試作品パネルで有効にしたとき。整理モードのリストのみ）

| キー | 動作 |
| --- | --- |
| j / k、gg / G | 項目間の移動、先頭・末尾へ |
| o / O | 直下・直上に新規追加して挿入モード |
| i / a | 選択中の項目を編集（i は行頭、a は行末から） |
| x ／ dd | 完了・解消の切替 ／ 削除 |
| J / K | 項目を下・上へ移動 |
| u / Ctrl+R | 取り消し／やり直し |
| Tab / Shift+Tab | 領域の移動 |
| Esc | ノーマルモードへ（Windows・Linux では Ctrl+[ も同じ） |

Windows・Linux では、Vimモード中の前日・翌日への移動は Alt+[ / Alt+] になります。

### マウス（補助）

- 項目のクリックで選択（Vimモード無効時はそのまま入力できる）、Vimモード中はダブルクリックで編集
- 行頭のチェック欄のクリックで完了・解消
- 項目の文字以外の部分をつかんで上下にドラッグすると並べ替え
- ノートの行の右クリックで「TODO へ送る」「障害へ送る」

## 試作品では確認できないこと

03 画面設計書 11章のとおり、次の4点はブラウザで動く試作品では確かめられません。本番の構成（Tauri と各 OS の WebView）で確認します（テスト計画書 4章）。

1. 日本語入力（IME）の確定 Enter などの判定。本番の macOS・Linux は WebKit 系で、ブラウザと挙動が異なります
2. OS 全体で効くショートカット（Mod+Alt+Y。Windows・Linux は Alt+Shift+Y）
3. 起動時間・入力応答などの性能基準
4. ブラウザ自体のショートカット（Mod+K、Mod+T、Mod+J など）と衝突するキー操作

このほか、試作品では次のものを作っていません。

- S-05 設定、S-06 エージェント変更履歴、S-07 外部課題の受信箱（Inbox は外部ツール連携を有効にした人にだけ出る決まりのため、試作品には出ない）
- ノート・振り返りの Vimモード、IME の自動切り替え
- 保存・バックアップ・書き出し（保存中の点と保存失敗の表示は、動きのまね）
- 書体の同梱（Inter と JetBrains Mono は、パソコンに入っていれば使い、なければ OS の標準書体で表示）
